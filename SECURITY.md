# Security policy

## Supported versions

There is no published release yet. Security fixes are handled on the repository's default development branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository, if enabled. If it is unavailable, contact the repository owner through the GitHub account [`tirodz`](https://github.com/tirodz) and request a private reporting channel. Do not post exploit details in a public issue before maintainers have had a chance to assess them.

No private email address or response-time guarantee is published because none has been provided by the maintainer.

## Scope notes

The app currently has no physical HID backend. It stores simulator profiles in local application data and imports user-selected JSON files after validation. Please include the app version, operating system, reproduction steps, and relevant logs, while removing secrets and personal data.
